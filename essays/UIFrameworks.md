> - Samadara Ginige

## What is UI Frameworks (I had the same question)

While HTML and CSS provide the most amount of control over a webpage for a software developer, learning how to use UI Frameworks can build a professional looking website in significantly less time than using pure HTML and CSS. It can also make webpages look much nicer as there’s consistent spacing for all of the different designs, and it can be more clear which parts of what webpages are used for certain utilities.
 
Web Design and UI Frameworks are important because most of the time, websites want to attract people to visit them. Having good design that’s consistent across every webpage on the website is important for the user experience. As marketing is considered very important for most products, Web Design is similarly important because without using words it shows why a user should visit that web page, or at least provides important information that the user was looking for in a concise, consistent way.

I feel like often software engineers can easily forget how important design is for how humans interact with all aspects of daily life. This is why learning UI Frameworks is important for any website that you're building. It gives people a reason to care about the idea that you're trying to get across, whether that's a product or service to sell, or just information that people might need for any variety of reasons.

## The Difficulty and Rewards of a Learning Curve

I’ve had quite a bit of experience in HTML and CSS from some coding exercises, and also LATEX feels very similar to HTML in a lot of ways. However, learning Bootstrap was a little bit difficult. To be honest, I feel like I have a better handle on it after everything we have learned so far, but I still feel like I can learn so much more and it will help me in the future. While part of me does sometimes think “I could just make a custom thing using CSS classes” out of frustration, I do still see the utility of Bootstrap. Once you get the hang of what Bootstrap can do, it makes designing a website a lot easier.

## What I learned and Final Thoughts

Overall, I think that everything learned from these exercises was very valuable. It makes me want to learn more about and experiment more with Bootstrap for my own education. Ultimately, I think it’s important for every software engineer to learn because the front end is just as important as the back end for web development. Humans in general like good design elements, and making sure that everything is easy to read and navigate plays a very important role in that process.
