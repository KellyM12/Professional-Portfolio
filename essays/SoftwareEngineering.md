## Finding Footing

Before I took this class, I wasn’t really sure what software engineering was all about. I figured it was just about coding for bigger projects that usually tend to involve multiple people. I wasn’t really sure of everything it entailed. We learned about Coding Standards (using ESLint) to keep code consistent, UI Frameworks (using react bootstrap) to have our web projects look much nicer with a learning curve, but overall less effort, and most importantly how to work together as a team using Agile Project Management.

## Coding Standards

Having good coding standards is very important if you want to make sure that everyone else who is interacting with your project (including other team members) understands what’s going on. While I had already known about the concept of coding standards, learning about ESLint was very interesting. It was definitely difficult to work with in the beginning. However, towards the end, I appreciated how it managed to keep things consistent, especially with our final project as we were dealing with many different files. 

Also, putting detailed comments into our project will hopefully help everyone in the future who may want to experiment with it. I have always thought that putting detailed comments to explain what each component does is very useful, not just for people who are new to the project and want to work on it, but also for the people who are already working on the project and forgot a component from 2 months ago and need to look at it and ask “oh yeah, what does this part do again?” 

## Design Patterns

This was truly a great learning experience for this class. While I realized that this is mostly true within coding and coding projects, being able to actually put a name to it, as well as the different types that exist, is very valuable. The most obvious example throughout this course was using the nextjs application template. However, this applies to every small component that can be used. For different parts of the website like navbars and footers, while they often looked different, they would usually function similarly. 

Having a good intuition about how multiple things can be used in different places is very important for programming within projects. I feel that being able to put names to the different components that we reused within our group project helped us to understand what the core important functions were, and how it would impact potential users.

## Agile Project Management

In my experience, having these skills is good for any type of programming project. Honestly, learning about project management skills and how different projects can be managed in any field is a very valuable skill. Not enough people understand that having good team leadership skills can also apply to being a regular team member in the future too.

While I had a little bit of experience in implementing Agile Project Management in previous classes, this class first introduced me to Issue-Driven Project Management. I definitely thought that this was a much easier way to keep tasks well divided, tidier, and improve communication among team members. I think in the future though, it would be good to make sure to agree, as a group, on what should be considered a separate issue, as some of ours took quite a while to finish while others were more immediate (wouldn’t have taken multiple days to do).

It was definitely nice to have different branches for everything, and keeping the main branch clear of changes for the most part was very helpful. Especially in case there were major errors, we knew that all we had to do was upload a previous branch that was working to main and double check any issues in the deployment.

## Looking Toward the Future

I really enjoyed everything that I learned from this course. I think I will be able to apply it to more of my learning in the future. Team management and the skills that come from working with others in a group project setting are always very useful for the future. Aside from that though, this project has changed how I will face programming and projects in the future. I feel it has given me the confidence to start on some projects that I had been holding back from for a while, partially just because of how busy I have been these last few years.
